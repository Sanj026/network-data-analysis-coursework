# Network Data Analysis coursework project
-> Install dependencies with `pip install -r requirements.txt`.
-> Run the scripts in this order: `python task_a.py`, `python task_b.py`, `python task_c.py`, `python part2_analysis.py`.
-> Input CSV files are stored in `datasets/`.
-> Part 1 figures are written to `outputs_part1/`.
-> Part 2 figures and summary outputs are written to `outputs_part2/`.
-> The report draft is `report_draft.md`.
